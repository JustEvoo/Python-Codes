# Python Practice

Currently learning Python. This repo is a collection of small scripts and mini-projects I am building along the way.

---

### Projects

* **`Banking_Program.py`** - Main entry point / scratch file for testing code snippets
* **`Number_Guessing_Game.py`** - A simple number guessing game
* **`Dice_Roller.py`** - Simulates rolling one or more dice
* **`Rock_Paper_Scissors.py`** - Classic Rock, Paper, Scissors game against the computer
* **`Quiz.py`** - A basic quiz program with questions and answers
* **`shopping_cart_program.py`** - A shopping cart simulation program
* **`Concession_Stand_Program.py`** - A concession stand ordering program with payment handling

---

### Getting Started

Clone the repository and navigate into the folder:
```bash
git clone https://github.com/JustEvoo/Python_Practice.git
cd Python_Practice
```
